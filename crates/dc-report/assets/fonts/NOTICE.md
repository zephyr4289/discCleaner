# Font Attribution

`LiberationSerif-Regular.ttf` is bundled inside this crate (embedded into
every PDF/A-3 archive it renders, as ISO 19005-3 requires fully-embedded
fonts).

- Typeface: Liberation Serif (metric-compatible with Times New Roman)
- Original designer: Steve Matteson (Ascender Corp), later revised by
  Google / The Document Foundation contributors
- License: SIL Open Font License 1.1
- Source: https://github.com/liberationfonts/liberation-fonts

The SIL OFL 1.1 license permits redistribution and embedding in
documents produced by this tool. A copy of the license text is
available at https://openfontlicense.org/open-font-license-official-text/.
